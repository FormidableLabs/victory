## Victory Native XL

For React Native, use [Victory Native XL](https://commerce.nearform.com/open-source/victory-native/), our rewrite of Victory Native designed specifically for React Native. It is published as the `latest` version of [`victory-native`](https://www.npmjs.com/package/victory-native).

```bash
$ npm install --save victory-native
```

See the [Victory Native XL docs](https://commerce.nearform.com/open-source/victory-native/) to get started.

## Legacy Victory Native

The legacy `victory-native` package, which shared its code and API with `victory`, is no longer developed in this repository. Its last release, `victory-native@37.3.6`, is still available on npm under the `legacy` tag. See the [available versions on npm](https://www.npmjs.com/package/victory-native?activeTab=versions).
